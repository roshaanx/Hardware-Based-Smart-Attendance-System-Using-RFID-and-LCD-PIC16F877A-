# Hardware-Based-Smart-Attendance-System-Using-RFID-and-LCD-PIC16F877A-
Designed and implemented a Smart Attendance System using the PIC16F877A microcontroller, integrating RFID, LCD display, buzzer alarm, and EEPROM-based attendance storage.

The system reads unique RFID card IDs via UART, validates them against registered IDs, and marks attendance automatically without manual intervention. A 16×2 LCD displays system status (“Attendance Marked”, “Invalid Card”), while a buzzer provides audio feedback for unauthorized cards. The circuit was simulated in Proteus and successfully tested for reliability, response time, and user interaction. The solution improves accuracy, reduces human error, and automates attendance processes in academic environments
